# 本地项目实验台验收记录

日期：2026-09-15。

## 本机验证结果

- Node.js v25.9.0；PostgreSQL 17.9；`projectctl` 实际入口 `/opt/homebrew/bin/projectctl`。
- TypeScript 检查通过，Vite 生产构建通过。
- 6 项领域单元测试通过：七阶段模板、前置门槛、交付与审核角色、退回、阻塞恢复、依赖循环。
- 独立测试数据库中完成 40 项接口、CLI 与浏览器检查，无浏览器运行错误。
- 已目视检查桌面和窄屏看板截图。

## 已覆盖的集成流程

创建项目 → 幂等重试 → 前置任务拦截 → 启动任务 → 无证据提交拦截 → Wiki 写入与历史查看 → 旧版本拒绝 → 全文检索 → 运行登记与完成 → 附件上传 → 提交 → 非审核人拒绝 → 人工退回 → 重提 → 审核通过 → 下游通知 → 依赖循环拒绝 → 导出恢复并校验依赖与附件 → 非法路径拒绝 → CLI dry-run → CLI 项目摘要 → 浏览器启动任务 → 浏览器编辑并保存 Wiki。

## 测试隔离

自动验收使用独立数据库 `project_lab_verification`、端口 4318 和 `data/verification` 文件目录，浏览器验收完成后停止测试服务。日常应用使用端口 4317 和数据库 `project_lab`。

## 尚未证明的事项

- 演示没有实际执行市场采集或业务分析，提效指标需真实工作样本。
- 角色是单用户本地模拟，未实现生产身份认证和多人权限隔离。
- 真实钉钉消息尚未接入；NAS 容器定义尚未实测。
- 文件系统与 PostgreSQL 的断电一致性、长期大数据量性能与多用户压力未进行验收。

上述边界不影响当前本地看板、Wiki、CLI、审核交接和备份恢复的预演使用。
