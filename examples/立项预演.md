# ERM 保温杯：本地预演立项

## 项目目标

以保温杯商品项目为载体，验证 Agent 管理任务、沉淀 Wiki 和进行人工审核的闭环。此处是软件预演资料，未读取或复制 Teambition 中的真实 ERM 项目数据。

## 输入依据

来源：用户在本次讨论中提出的需求。核心是项目看板与项目 Wiki；主管按 SOP 建立项目，执行人通过 Agent 完成工作，交付结论回写项目，主管审核后通知后续节点。

## 交付标准

1. 每个节点有负责人、审核人、验收标准与依赖关系。
2. 分析结论保存为可读取的 Markdown，并关联原始资料或附件。
3. 任务交接具有可查的操作记录。
4. 用实际耗时与质量评价验证效果。

## 预演范围

预演采用固定输入，验证软件行为。市场数据、竞品销量、消费者需求和推广建议均需在真实业务执行中采集并核实。

## 下一步

执行一次真实市场调研：主管提供商品与市场范围，Agent 读取项目知识、调用相应业务能力、写入有依据的报告，再提交审核。
